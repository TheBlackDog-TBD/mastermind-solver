# Security Policy

## Supported Versions

Only the latest published version is supported.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it
privately through GitHub Security Advisories.

Please do not publicly disclose vulnerabilities before
they have been investigated.

## Security Measures

This project implements:

- Content Security Policy (CSP)
- Strict input validation
- Safe DOM manipulation
- Local storage validation
- No external JavaScript dependencies
- No backend or database
- No collection of personal information

## Scope

Mastermind Assistant is a client-side application.

It does not process payments, authenticate users,
or store sensitive information.
